Usage Rules
Do's and Don'ts
✅ DO
✅Use Royal Blue (#2B4FD4) for all primary CTAs, nav, and interactive elements
✅Use Amber only for community badges, highlights, and events — not for primary buttons
✅Use Emerald for pay amounts, hired status, success states
✅Keep background as #F8FAFF (blue-tinted white) — feels like the logo's world
✅Always use Deep Navy (#0F1F6B) for sidebar headers and dark surfaces
✅Show REKKOMO brand name next to Apna Sheher in the navbar always
🚫 DON'T
🚫Never use Saffron/Orange (#E8621A) as a primary color — it fights with your blue logo
🚫Never use a warm cream/paper background — use blue-tinted #F8FAFF instead
🚫Never mix Amber and Royal Blue on the same interactive element (button, link)
🚫Never use Coral Red except for error states and urgent alerts
🚫Never render Hindi text in Plus Jakarta Sans — always use Noto Sans Devanagari
🚫Never use more than 3 colors in a single card component
